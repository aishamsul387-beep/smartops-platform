# 01 — Project Overview

## Project Name
SmartOps WMS AI

## Project Purpose
SmartOps WMS AI is a warehouse management and operations platform designed to provide a structured frontend and backend foundation for inventory, warehouse activity, procurement, reporting, and AI-assisted workflows.

## Current Delivery Scope
The project currently provides a deployed and working baseline that includes:

- authentication
- protected routes
- dashboard
- inventory foundation
- warehouse foundation
- tasks foundation
- procurement/orders foundation
- reports foundation
- AI assistant placeholder foundation
- deployment and verification scripts

## Current Deployment Targets
- Frontend: Vercel
- Backend: Render

## Current Public URLs
- Frontend: https://smartops-platform.vercel.app
- Backend: https://smartops-platform-backend.onrender.com/api

## Current Local URLs
